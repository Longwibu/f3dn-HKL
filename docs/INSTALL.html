DÀNH CHO BAN GIÁM KHẢO

Cài PhishGuard.
Thử ngay trong trình duyệt.

Dùng Chrome hoặc Microsoft Edge trên máy tính. Không cần cài Node.js, npm, Git, chạy lệnh hay khởi động server.

Kiểm tra đường link

Cài xong là dùng được. Không cần API key.

Lọc Facebook bằng AI

Cần Internet, đăng nhập Facebook và API key Gemini có quyền dùng Hydrogen + Decision, còn hạn mức. Bản ZIP không chứa key.

1. Cài extension

  1. Giải nén file phishguard-chrome-edge.zip. Tìm thư mục PhishGuard có file manifest.json bên trong.
  2. Mở trang quản lý tiện ích. Sao chép chrome://extensions vào thanh địa chỉ Chrome. Với Edge, dùng edge://extensions.
  3. Bật Developer mode / Chế độ dành cho nhà phát triển.
  4. Bấm Load unpacked / Tải tiện ích đã giải nén, chọn thư mục PhishGuard.
  5. Bấm biểu tượng tiện ích hình mảnh ghép, ghim PhishGuard lên thanh công cụ. Bấm icon để mở popup; tải lại Facebook nếu trang đã mở từ trước.
PhishGuard/                  ← chọn thư mục này
├── manifest.json
├── popup.html
├── background.js
└── HUONG-DAN-CAI-DAT.html

Giữ thư mục PhishGuard tại chỗ sau khi cài. Không xóa hoặc di chuyển vì trình duyệt đọc extension từ đây.

Bản này cài bằng Load unpacked, chưa có trên cửa hàng tiện ích. Nếu tải lại, chọn bản ZIP đã build, không chọn Source code.

Tham khảo cách cài chính thức của Chrome và Microsoft Edge.

2. Thử kiểm tra link

Mở popup PhishGuard, nhập https://facebook.com.evil.test vào ô kiểm tra link, rồi bấm Kiểm tra.

Kết quả chỉ ra miền đăng ký thật là evil.test. Thao tác này phân tích đường link, không mở website đích.

3. Thử bộ lọc Facebook

Chuẩn bị key cá nhân hoặc key được cung cấp riêng, có quyền truy cập gemini-4-hydrogen và gemini-decision-1.

  1. Trong popup, mở Kết nối Gemini, dán key, tích đồng ý gửi yêu cầu và chữ trong bài tới Google, bấm Lưu kết nối.
  2. Nhập yêu cầu bên dưới, bấm Thêm vào bộ lọc. Có thể Sửa / Xóa từng mục sau đó.

“Tôi không muốn thấy cờ bạc mạng và quảng cáo vay nóng. Vẫn cho tôi xem bài cảnh báo tác hại.”

  1. Chọn thu gọn có lý do và nút xem, làm mờ, hoặc ẩn hoàn toàn không thông báo.
  2. Mở bảng tin Facebook và tải lại trang. Xem trạng thái cùng Log hoạt động trong popup.

Extension quét trước tối đa 30 bài Facebook đã tải vào trang. Hiện chỉ đọc chữ, chưa phân tích nội dung ảnh/video; AI có thể nhầm. Lượt gọi dùng hạn mức của key. Key lưu trên máy, không mã hóa; không chia sẻ key công khai. Chưa kết nối Gemini thì AI chưa chạy, kiểm tra link vẫn dùng được.
